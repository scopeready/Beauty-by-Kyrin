# Beauty by Kyrin

Production website for Beauty by Kyrin, a Las Vegas hair stylist inside Venus Salon.

## Local review

Serve this directory with any static web server. For example:

```powershell
npx serve .
```

Then open the local URL shown by the server.

## Quality check

```powershell
npm run check
```

The site is configured for Git-connected deployment on Vercel. The canonical production domain is `www.beautybykyrin.com`.
